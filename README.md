# People Search OSINT Tool

A personal portfolio project that lets a user search for a person by name and 
retrieve publicly available information about them, aggregated from multiple 
public sources.

## Sources (planned)
- Google Custom Search API — general web presence
- GitHub API — public developer profiles and repositories
- Reddit API — public posts and comments

## Scope & Ethics
This project only accesses publicly available data through official, approved 
APIs. It does not scrape or bypass authentication, does not access private 
accounts or private content, and is strictly non-commercial. Built as a 
demonstration of API integration, data aggregation, and privacy-conscious 
design for a Computer Science / Cybersecurity portfolio.

## Status
🚧 In development.

## Stack
Node.js, Express, and API integrations (Google Custom Search, GitHub REST API, 
Reddit Data API).
